# 💰 AI Financial Companion

An **AI-powered personal finance management app** that helps users track expenses, understand spending habits, detect financial risks, and make smarter financial decisions.

## 🚀 Features

* 💰 **Expense & Income Tracking** — Manage daily transactions.
* 🤖 **AI Expense Categorization** — Automatically categorize expenses.
* 📊 **Smart Dashboard** — View income, expenses, savings, and spending patterns.
* 🎯 **Budget Management** — Set and monitor monthly budgets.
* 🚨 **Financial Risk Detection** — Identify unusual spending and potential financial risks.
* 🧠 **AI Financial Insights** — Get personalized recommendations based on spending behavior.
* 🔄 **Recurring Expense Detection** — Identify subscriptions and repeated payments.
* 🎯 **Savings Goals** — Set and track financial targets.
* 💬 **AI Financial Assistant** — Ask questions about your spending and savings.
* 🔔 **Smart Alerts** — Get notified about budget limits and unusual activity.

## 🛠️ Technology

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js
* **AI/ML:** Python + AI APIs
* **Database:** PostgreSQL / MongoDB
* **AI Tools:** Gemini, ChatGPT, Bolt.new, Gamma

## 🔄 How It Works

**Add Transactions → AI Categorization → Spending Analysis → Risk Detection → AI Insights → Personalized Action**

## 🎯 Goal

To transform a traditional expense tracker into an **AI Financial Companion** that helps users not only record their money, but also **understand, manage, and improve their financial habits**.
